Copy of the ReadGurbani audio tagging tool, fixed so the Gurbani panktis load again. Data: Gursevak / readgurbani.com SGGS database (UIDs as in the original). Sehaj Paath tagging is already complete — this copy is mainly for Katha tagging.

100%

Instructions: Read before starting NOTE: The instructions for Sehaj Paath are similar, but there is only one tag per Tukh.
  1. Start at the lower end of your assigned Ang range. Enter the Ang number and click on the "Load" button.
  2. The lines in the current Ang will load, along with the previous and next Angs (to cover overlap). The lines in the current Ang will be highlighted light yellow.
  3. Select your assigned audio track number from the dropdown. If an Ang only has one track (majority of cases), the dropdown will be disabled.
  4. Some tracks may appear in more than one Ang due to overlap. This is expected. Only tag the track once.
  5. The selected audio track will be loaded into the audio player.
  6. Play the audio and listen for the first Gurbani Tukh read by the Paathi Singh.
  7. Find the Tukh in the list. It will be somewhere in the middle, since the list includes the previous and next Angs as well. Use Ctrl+F/Cmd+F to search if needed.
  8. Restart the audio and press the tag button next to the Tukh as soon as you hear it. The first Tukh can be tagged at 0 seconds before the audio starts playing.
  9. Try to accurately tag it as soon as the Paathi Singh starts the Tukh.
  10. Check the tag by rewinding the audio a few seconds before the tag. When the player hits the timestamp, the tagged row will be highlighted.
  11. If you make a mistake, you can Undo the last tag.
  12. Once you check that the tag is accurate, move on and listen for the next Tukh. Don't skip ahead.
  13. Sometimes the Pangti is repeated multiple times, either by itself or with the whole Shabad/Pauri. Tag the Tukh every time you hear it. Each Tukh can have multiple timestamps.
  14. Tag every Tukh in the track. Leave the other Tukhs blank.
  15. Once this is done, click on the "Export Tagged" and "Export Flat" buttons to download the data.
  16. Once your assigned Angs have been completed, share the files with a sevadaar and open a Github PR if you have access (ask for instructions).
